# 数据来源与原件

本次题目的唯一数据输入为 GitHub 仓库公开 API：

<https://api.github.com/repos/org2AI/ORG2>

## 请求与保存

执行真实请求并保存收到的响应。记录实际请求 URL、请求时间（含时区）、HTTP 状态和响应 Content-Type；保留分析用到的响应字段及其原始类型。无需把认证凭据放入请求说明或成果文件。

实际响应为 JSON 时保存为 `data/raw-response.json`；实际响应不是 JSON 时保存为 `data/raw-response.txt`，在验证结果中说明解析失败。网络请求未取得响应时如实保存错误与已执行命令，不生成假的响应文件。

单个原始数据文件不超过 1 MiB。超过限制时记录实际情况并停止把它作为本次完整原件提交；不得悄悄截断数据后宣称保存了完整响应。

## 验证与结论

以学生当次保存的原件为分析依据，不用教师之后重新请求的数据替代。检查状态、数据类型、所用字段是否存在及其值是否符合分析前提；把实际验证命令和输出写入 `results/validation.md`。

字段名或数字本身不能证明项目质量、开发者能力或因果关系。选择 AI 在本次实际对话中提出的一个假设，用原始响应、必要的字段说明或额外真实证据核对，记录支持、修正或暂时无法判断的结论。额外证据也必须保留来源和获取时间。

请求失败、字段缺失或验证失败都应保留实际情况。不得为了满足验收要求编造成功请求、错误修复经历或测试结果。
