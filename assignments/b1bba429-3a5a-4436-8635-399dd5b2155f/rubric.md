# 审阅依据

教师依据实际成果与已授权记录核对以下内容，不自动打分：

| 项目 | 核对内容 |
| --- | --- |
| 问题拆解 | 是否区分请求、保存、验证和分析，是否说明执行顺序和依赖。 |
| 数据验证 | 是否保存本次实际响应，是否检查状态、类型和所用字段，结论能否由原件支持。 |
| AI 假设核对 | 是否识别实际 AI 假设、检查证据，并说明采纳、修正或保留判断的原因。 |
| 错误与限制 | 是否如实记录失败、未执行项和证据缺失；出现错误时能否说明实际修正。 |
| 关键决策 | 是否由学生核对关键结论、成果 commit 和分享范围，而不是把确认交给模型代做。 |

每项意见引用具体成果文件或应用提供的源事件引用。未读取到相关证据时明确说明缺失，不能根据最终答案推断学习过程。
